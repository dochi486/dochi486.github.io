### NBA RISE

- 사용 언어 : C#
- 개발 환경 : Unity
- 게임 장르 : CCG 스포츠
- 목표 플랫폼 : 모바일
- 타깃 국가 : 글로벌
- 개발사 : ㈜그라비티네오싸이언
- 담당역할 : 컨텐츠 개발
  [선수 카드 수집 게임 컨텐츠 작업]
  <br>- 연속 구매 형태 BM UI 작업
  <br>ㄴ무한스크롤(OSA) 적용 작업
  <br>ㄴ구매 후 스크롤 넘어가는 연출 OSA로 처리
  <br>- 도감 구현 및 카드 해금 보상 처리 작업
  <br>ㄴ팀별 필터 적용
  <br>ㄴ해금되지 않은 선수와 해금된 선수 구분
  <br>ㄴ신규 해금된 선수만 보이는 탭 생성
  <br>- 가챠팩 작업
  <br>ㄴ가챠 소환권 아이템 추가 작업
  <br>ㄴ가챠 연출 추가 작업
  <br>ㄴ게임 강제 종료 시 가챠 예외처리 작업
  <br>- 비밀번호 자물쇠처럼 숫자 입력하는 UI 모듈화 작업
  <br>ㄴ양쪽, 위아래 화살표로 숫자를 입력하는 UI 프리팹 작업
  <br>ㄴ일정 수치 넘어가면 이벤트 발화하도록 처리
  <br>ㄴ최소 수치 이하로 설정 시에도 이벤트 발생 처리
  <br>ㄴ여러개의 수치 입력기가 있을 때 하나의 입력기만 활성화 되도록 그룹화 작업
  <br>- 거래소/경매장 가격 동향 꺾은 선 그래프 UI 렌더러 작업
  <br>ㄴ유니티 메쉬를 이용해 꺾은 선 그래프 표현 작업
  <br>ㄴ서버에서 주는 날짜와 가격 딕셔너리로 묶어서 처리
  <br>- 길드 점령전 UI 작업
  <br>ㄴ점령전 랭킹 보상 리스트 UI 작업
  <br>ㄴ실시간 유저 기여도 랭킹 UI 작업
